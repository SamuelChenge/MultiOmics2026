# 1. Do the pieces fit together?

The most dangerous QC failure is silent mis-alignment: if the count-table
columns and the metadata rows were in a different order, every test would be
wrong and nothing would warn us. `read_counts()` refuses to return if the
sample ids of the two count tables and the metadata are not exactly the same
set, and it reorders the columns to match the metadata — but it does **not**
check the cytokine table, so we check all four tables ourselves here, both for
the same *set* of ids and for the same *order*.


::: {.cell}

```{.r .cell-code}
# Every cell is turned into text, so one column can hold counts and yes/no answers.
tibble(
  check = c(
    "samples in metadata",
    "species table: features x samples",
    "gene table: features x samples",
    "cytokines rows",
    "sample_id appears more than once?",
    "participant appears more than once?",
    "species ids same set as metadata?",
    "gene ids same set as metadata?",
    "cytokine ids same set as metadata?",
    "species columns ordered like metadata?",
    "gene columns ordered like metadata?",
    "cytokine rows ordered like metadata?",
    "negative or fractional counts anywhere?",
    "non-integer counts?"
  ),
  result = c(
    nrow(md),
    str_c(nrow(sp), " x ", ncol(sp)),
    str_c(nrow(ge), " x ", ncol(ge)),
    nrow(cy),
    anyDuplicated(md$sample_id),
    anyDuplicated(md$participant_id),
    setequal(md$sample_id, colnames(sp)),
    setequal(md$sample_id, colnames(ge)),
    setequal(md$sample_id, cy$sample_id),
    identical(colnames(sp), md$sample_id),
    identical(colnames(ge), md$sample_id),
    identical(cy$sample_id, md$sample_id),
    any(sp < 0) || any(ge < 0),
    any(sp != round(sp)) || any(ge != round(ge))
  ) |>
    as.character()
)
```

arms are compared on the microbiome.

# 3. Missing values

zero reads), so missingness lives in the spreadsheet-like tables. For the
metadata the answer is good news: **not a single cell is missing** — every one
of the 8 columns (`sample_id`, `participant_id`, `arm`, `bv`, `nugent`, `ph`,

be dropped for lack of arm or batch information and no variable needs

# 5. Dominance: is one feature eating each sample?

Both tables are **compositional**: sequencing gives us proportions, not
absolute amounts, so every table must sum to the library size. That means a
huge read count for one feature mechanically shrinks all the others. Some
dominance is expected — vaginal communities are often 90 % one *Lactobacillus*
— but near-total domination is worth seeing explicitly.


::: {.cell}

```{.r .cell-code}
top_share <- function(m) apply(m, 2, max) / colSums(m)
qc$top_species <- top_share(sp)
qc$top_gene    <- top_share(ge)

worst_sp <- qc |> slice_max(top_species, n = 3) |>
  transmute(sample_id, share = str_c(round(100 * top_species, 1), "%"))

knitr::kable(worst_sp, caption = "Samples whose single most abundant species takes the largest share")
```

# 6. Anything odd inside the RNA-seq?

The largest gene share in any sample is 29% —
in `B093`, nearly a third of all reads come from **HBB**, the beta chain of
haemoglobin. Haemoglobin genes are the classic signature of blood
contamination in mucosal swabs: the sample picked up red blood cells, and RNA
from blood crowded out cervical/vaginal transcripts. It is worth remembering
when interpreting `B093` specifically, but a quarter of samples carry some
HBB signal and the difference is quantitative, not broken, so we keep the
sample.

# 9. First look: ordination

Ordination gives every sample one point on a map: samples with similar
feature profiles sit close together. It is the strongest early check that the
data has real structure, and that no sample sits wildly alone. We colour the
points by **community**, using the same rule as notebook 02 — a sample is
*lactobacillus* when the genus *Lactobacillus* accounts for at least half of
its species reads, otherwise *anaerobe*.


::: {.cell}

```{.r .cell-code}
# Same rule as notebook 02, applied to the group_b species table.
lacto_taxa <- d$taxonomy |> filter(Genus == "Lactobacillus") |> pull(taxon)
qc$lacto_fraction <- colSums(sp[lacto_taxa, , drop = FALSE]) / qc$lib_species
qc$community <- ifelse(qc$lacto_fraction >= 0.5, "lactobacillus", "anaerobe")

knitr::kable(qc |> count(community), caption = "Samples per community label")
```

```{.r .cell-code}
library(microViz)
library(phyloseq)

ps_species <- as_counts(dataset = "group_b", table = "microbiome", data = d)
sd <- as(sample_data(ps_species), "data.frame")
sd$community <- qc$community[sd$sample_id]
sample_data(ps_species) <- sample_data(sd)

# One knob each: transform -> distance -> ordination.
ord_bray    <- ps_species |> tax_transform("identity") |> dist_calc("bray")    |> ord_calc("PCoA")
ord_jaccard <- ps_species |> tax_transform("binary")   |> dist_calc("jaccard") |> ord_calc("PCoA")
ord_clr     <- ps_species |> tax_transform("clr", zero_replace = "halfmin") |> dist_calc("euclidean") |> ord_calc("PCoA")

plot_ord <- function(ord, name) {
  eig <- attr(ord, "ord")$CA$eig
  sh  <- round(100 * eig / sum(eig), 1)
  ord_plot(ord, axes = 1:2, color = "community") +
    labs(title = name,
         x = sprintf("Axis 1 (%s%%)", sh[1]),
         y = sprintf("Axis 2 (%s%%)", sh[2]))
}
scree_shares <- function(ord, name) {
  eig <- attr(ord, "ord")$CA$eig[1:8]
  tibble(distance = name, axis = seq_along(eig), share = eig / sum(eig))
}
scree <- bind_rows(
  scree_shares(ord_bray, "Bray-Curtis"),
  scree_shares(ord_jaccard, "Jaccard"),
  scree_shares(ord_clr, "CLR + Euclidean")
)

wrap_plots(
  plot_ord(ord_bray, "Bray-Curtis"),
  plot_ord(ord_jaccard, "Jaccard"),
  plot_ord(ord_clr, "CLR + Euclidean"),
  ncol = 3
) / ggplot(scree, aes(axis, share)) +
  geom_col(fill = "grey40") +
  facet_wrap(~ distance) +
  labs(title = "Scree: share of variation held by the first 8 axes",
       x = "Axis", y = "Share of variation") +
  theme_bw()
```

# Verdict

- **Structure:** all four tables (metadata, species, genes, cytokines) agree on
  the same 93 samples and 93 participants, in the same order; counts are
  non-negative integers. No structural problems.
- **Balance:** 28 pill / 39 injectable / 26 ring, both sequencing batches
  present in every arm. Baseline variables are balanced across arms except a
  small difference in vaginal pH (p = 0.02) worth remembering at analysis time.
- **Missing data:** the metadata is 100 % complete. `B018` and `B029` lack all
  cytokines (keep for the rest; drop them for cytokine analyses). No other
  missing values anywhere.
- **Flagged samples:** nine low-depth microbiome samples (still usable);
  `B030` is a near-monoculture of *L. iners* (real biology, watch it in
  ordinations); `B093` carries heavy blood signal in its transcriptome
  (remember when interpreting it).
- **Nothing so broken that it must be removed before analysis.**

## Choices made

- Flagged low-depth samples at **below half the median library size**, rather
  than a fixed read count, so the rule adapts to the table's own spread; a
  fixed floor (e.g. 10,000 reads) would be more standard in published
  microbiome pipelines.
- Did **not remove any samples** in the QC document itself — removal decisions
  are deferred to the analysis documents, where we can see whether a flagged
  sample actually drives a result.
- Did **not impute the 30 missing cytokine values** — complete-case analysis
  (dropping the two affected samples only for cytokine questions) is simpler
  and safer.
- Used **prevalence curves** to preview feature filtering but applied no
  filter here; the filter thresholds belong to each analysis's "Choices made".
- Checked batch only via **library size** — the first-look ordination above is
  coloured by community, not batch; ordinations coloured by batch, and on the
  gene table, still belong to the analysis documents.
- Computed the ordination **inside this document** rather than embedding the
  pre-made `ordination_three_ways.png`, which turned out to have been built
  from the instructional cohort (471 samples) instead of Study B. Rebuilding
  here means the figure, its numbers and this document all come from the same
  93 samples.
- Defined community **inside this document** with the notebook 02 rule
  (Lactobacillus ≥ 50 % of species reads) rather than reading
  `data/my_sample_groups.csv`, which only holds labels for the instructional
  cohort; a stricter rule (e.g. 60 %, or a third group) is the alternative.
- Ran the ordination on the **unfiltered species table**; filtering rare
  features first (as the analysis documents will) is the alternative and may
  sharpen the picture.
- For the baseline check we used **Kruskal–Wallis** for Nugent score and pH
  (non-normal, three groups) and **Fisher's exact test** for BV and STI
  (small counts in some cells); a chi-squared test would be the alternative,
  but some expected counts are too small for it to be trustworthy. We report
  the pH difference rather than adjust for it here — the decision to include
  pH as a covariate belongs to each analysis document's "Choices made".
