# Slide figures — Study B

One high-resolution PNG (300 dpi, 3000 × 1500 px unless noted) per figure,
ready to drop into PowerPoint or Google Slides. Each file was generated by
`../make_slide_figures.R` from the workshop datasets — rerun that script if
the data or the analysis documents change.

## The three question figures (use these on results slides)

| File | Slide it belongs to | What it shows | The number that goes with it |
|---|---|---|---|
| `q1_species_pcoa_by_arm.png` | Q1, slide 11 | Species-table PCoA (CLR + Euclidean), coloured by pill / injectable / ring. Arms overlap heavily. | PERMANOVA: 2.8 % of variation, p = 0.172 (n = 93) — **no** three-way difference |
| `q2_gene_pcoa_by_arm.png` | Q2, slide 16 | Gene-table PCoA, coloured by arm. | Three-arm PERMANOVA 2.7 %, p = 0.101; pooled ring vs systemic 1.7 %, p = 0.041 (borderline) |
| `q2_volcano_ring_vs_systemic.png` | Q2, slide 19 | DESeq2 volcano, ring vs pooled systemic. Red = FDR < 0.05. | 165 genes at FDR < 0.05 (88 up in ring), n = 26 vs 67 |
| `q3_gene_pcoa_by_community.png` | Q3, slide 24 | Same gene PCoA, coloured by community type (lactobacillus vs anaerobe). | Head-to-head: community 1.4 % p = 0.117 vs method 1.6 % p = 0.053; 312 vs 165 genes at FDR < 0.05 |
